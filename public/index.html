🔐 Авторизация AntiLag Router

ℹ️ Справка: Режимы балансировки AntiLag

🛡️ Игровой режим (Gaming Mode):

Предназначен для сессий в онлайн-играх (CS2, Valorant, Dota 2, GTA V, Apex), где смена IP во время матча приводит к кику с игрового сервера. Программа удерживает выходящий IP-адрес для сессии до последнего и переключает на резервный сервер только при реальном отвале (>2.5 сек).

⚡ Веб / Стриминг (Fast Switch):

Предназначен для мгновенной загрузки веб-страниц, видео и тяжелого контента. При появлении микро-джиттера (>150мс) или потерь пакетов (>10%) балансировщик агрессивно перенаправляет новые сессии за ~50 мс на самый быстрый сервер в реальном времени.
